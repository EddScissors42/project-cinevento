# project-cinevento
Um projeto OO de Java, para final da Disciplina POO 2026.1

Um mini-sistema de Cinema com seleção de filmes, gerenciamento de ingressos e salvamento desses dados!

## Estrutura do projeto:
```text
├── irl [Funções (get/set)]
│   ├── Filme.java
│   ├── Cliente.java
│   ├── Filme.java
│   ├── Ingresso.java
│   └── Sessao.java
├── repository
│   ├── Cinema.java [Interface do sistema]
│   └── TipoSala.java [Enum]
├── service
│   ├── FilmeService.java
│   └── SessaoInexistenteException.java
├── ui
└── Main.java

Tecnologias
├── Java 25
└── Maven
└── JFrame
```
